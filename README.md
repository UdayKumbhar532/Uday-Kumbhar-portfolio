## 🌟 Highlights & Features

- 🛸 **Floating Glassmorphism Navbar**: Centered pill capsule with dynamic active section tracking, theme switcher, and instant resume download.
- ⚡ **Futuristic Hero Section**: Live status availability badge (`Open to Internships & Fresher Opportunities`), dynamic typewriter designation rotator, core technology chip strip, and high-resolution personal portrait with ambient backlighting.
- 📬 **EmailJS Contact Integration**: Fully functional contact form sending messages directly to Gmail with client-side regex validation, invisible honeypot anti-spam protection, and animated modal feedback.
- 🔮 **Animated Success & Error Modals**: Futuristic centered glassmorphic notification popups with SVG checkmark drawing animations and auto-dismiss timing.
- 📄 **Interactive Certificate & Resume Viewer**: Embedded modal viewer with zoom controls, fullscreen mode, and direct PDF downloads.
- 🌓 **Adaptive Dual Theme (Dark / Light)**: Midnight-purple & deep navy palette in Dark Mode; crisp, high-contrast lavender aesthetic in Light Mode.
- 📱 **100% Fully Responsive**: Fluid typography, responsive grids, and touch-friendly navigation across all viewport sizes.

## 🚀 Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/UdayKumbhar532/Uday-Kumbhar-portfolio.git
   cd Uday-Kumbhar-portfolio
   ```

2. **Launch with any local HTTP server**:
   - **VS Code Live Server**: Right-click `index.html` &rarr; *Open with Live Server*.
   - **Python**:
     ```bash
     python -m http.server 8000
     ```
   - Then open `http://localhost:8000` in your browser.
